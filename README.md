# Button Field

A pixel-art incremental game about a red button, treasure chests, and the gear you find across five fields.

[Play on GitHub Pages](https://wld80721.github.io/button-field/) or download `index.html` and open it in a browser. The standalone file includes its art, styles, scripts, and synthesized sound. To move your progress between browser origins or devices, use **Save & settings** to export and import a save.

See [Development](DEVELOPMENT.md) for build commands and architecture, [Progress](PROGRESS.md) for the current handoff, [Development plan](DEVELOPMENT_PLAN.md) for upcoming phases, and [Changelog](CHANGELOG.md) for releases.
